# Customer Segmentation Project
# Overview

This project implements customer segmentation using K-Means clustering to group customers based on their purchasing behavior and demographic features.
Customer segmentation is a critical task for businesses to understand their customer base, tailor marketing strategies, and improve customer retention.


# Features

- Data preprocessing and cleaning
- Feature scaling for optimal clustering
- K-Means clustering algorithm
- Visualization of customer clusters
- Insights derived from customer segments

# Technologies Used

- Python 3.x
- Pandas
- NumPy
- Matplotlib & Seaborn
- Scikit-learn

# Dataset

The dataset used is the Online Retail dataset contains transactional records for a UK-based, registered non-store online retail company. 
It covers all transactions between December 1, 2010, and December 9, 2011, totaling 541,909 instances with 6 features. 
The dataset is multivariate, sequential, and time-series in nature, with features of type integer and real.
It is commonly used for tasks such as classification and clustering in the business domain. 
Chen, D. (2015). Online Retail [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5BW33.
