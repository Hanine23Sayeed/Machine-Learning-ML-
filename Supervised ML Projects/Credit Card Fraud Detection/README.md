# Credit Card Fraud Detection (Logistic Regression)

Credit card fraud detection is one of the most important applications of machine learning in the financial and banking industry. With the rapid growth of online transactions, fraudulent activities have become more frequent and more sophisticated, leading to significant financial losses for both customers and institutions. Detecting fraud quickly and accurately is critical to ensure secure transactions and maintain trust in digital payment systems.

This project presents a machine learning–based framework for detecting fraudulent credit card transactions using a real-world credit card fraud dataset. Since fraud detection datasets are typically highly imbalanced (fraud cases are very rare compared to legitimate transactions), this study addresses the imbalance problem by applying appropriate balancing techniques to improve model performance and ensure fair learning.

The project follows a complete data science pipeline, including data preprocessing, exploratory analysis, data balancing, model training, and evaluation. A Logistic Regression model is implemented as an effective and interpretable classification algorithm, and the model performance is evaluated primarily using Accuracy to measure prediction correctness.

# Workflow Overview

The project is organized into a structured workflow consisting of the following stages:

- Data Preprocessing

- Exploratory Data Analysis (EDA)

- Handling Imbalanced Data (Balancing Technique Applied)

- Data Splitting (Train/Test Split)

- Model Development: Logistic Regression

- Model Evaluation: Accuracy

Each stage contributes to building a reliable and efficient fraud detection system capable of identifying fraudulent transactions from legitimate ones.
